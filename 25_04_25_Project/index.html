HTML and CSS Basics

HTML:

  • What is the purpose of the <head> section?
    It contains meta info, title, and links to CSS or JS. It’s not visible on the page.
  • How do you create a hyperlink?
    <a href="https://example.com">Click Here</a>
  • Which tag inserts an image?
    <img src="image.jpg" alt="description">
  • <div> vs <span>
    <div> is a block element. <span> is inline.
  • Create unordered and ordered lists:
    <ul><li>Item</li></ul>
    <ol><li>Item</li></ol>
  • Open link in a new tab:
    <a href="link" target="_blank">Open</a>
  • Create a table:
    Use <table>, <tr>, <td>, <th>
  • Purpose of alt in <img>:
    It gives alternate text if the image doesn’t load.
  • Internal CSS styles:
    Add a <style> tag inside <head>.

CSS:

  • What is CSS?
    CSS = Cascading Style Sheets. It styles HTML pages.
  • Apply CSS using <style>:
    <style> p { color: red; } </style>
  • Inline vs Internal vs External:
    Inline: inside element, Internal: inside <style>, External: separate .css file
  • Change background color:
    body { background-color: lightblue; }
  • Change font size:
    p { font-size: 18px; }
  • Margin vs Padding:
    Margin = space outside the box, Padding = space inside
  • Add border:
    div { border: 1px solid black; }
  • Why use CSS?
    To make HTML look nice and styled.
